# 요청-응답과 메모리 CRUD 체크리스트

## 학생 체크리스트

- [ ] `POST /posts` 생성 흐름을 설명할 수 있습니다.
- [ ] `GET /posts`와 `GET /posts/{id}`를 실행할 수 있습니다.
- [ ] Controller와 Service 역할 차이를 설명할 수 있습니다.
- [ ] 요청 DTO와 응답 DTO를 왜 나누는지 말할 수 있습니다.
- [ ] 서버를 재시작하면 데이터가 사라지는 이유를 설명할 수 있습니다.
- [ ] Swagger에서 직접 API를 실행할 수 있습니다.

## 강사 / 발표 / PPT 체크리스트

- [ ] 요청 -> Controller -> Service -> 메모리 저장소 -> 응답 흐름 그림이 있는가
- [ ] POST / GET 요청 예시가 준비되어 있는가
- [ ] DTO와 내부 데이터 역할 차이를 설명할 수 있는가
- [ ] 메모리 저장의 장점과 한계를 한 장면으로 보여줄 수 있는가
- [ ] 다음 시퀀스에서 DB 저장으로 넘어가는 이유를 연결할 수 있는가
